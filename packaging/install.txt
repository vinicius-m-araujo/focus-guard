FocusGuard — instalação no Windows

Opção recomendada: execute focusguard-X.Y.Z-amd64.msi como administrador.
O instalador registra os serviços FocusGuard e FocusGuardWatchdog, instala
os executáveis em C:\Program Files\FocusGuard e cria o atalho do painel.

Alternativa: extraia o ZIP Windows (amd64 ou arm64) e execute no PowerShell
elevado, dentro da pasta extraída:
  .\install-daemon.ps1 install
  .\install-daemon.ps1 status

Abra o painel pelo atalho FocusGuard ou tray. O uso normal não exige elevação.
Dados persistidos: C:\ProgramData\FocusGuard.
Para remover a instalação, use Aplicativos Instalados ou:
  .\install-daemon.ps1 uninstall

Linux não é suportado nesta distribuição.
